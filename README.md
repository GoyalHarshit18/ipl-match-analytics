# 🏏 IPL Match Analytics — Data-Driven Insights from IPL History

## 📌 Project Overview

This project analyzes ball-by-ball IPL data to uncover strategic insights related to:

* Toss impact on match outcomes
* Batting first vs batting second performance
* Match phase dominance
* Player performance trends
* Match competitiveness and close finishes

The analysis was performed using Python-based data analytics and visualization techniques to transform raw cricket data into meaningful strategic insights.

---

# 🎯 Objectives

* Analyze whether winning the toss affects match results
* Compare the success rates of batting first and batting second
* Study scoring patterns across Powerplay, Middle Overs, and Death Overs
* Identify top-performing batters and bowlers
* Measure the frequency of closely contested matches
* Extract strategic insights using ball-by-ball IPL data

---

# 📂 Dataset

The dataset was obtained from Cricsheet in JSON format and converted into a structured CSV format using Python preprocessing techniques.

### Dataset Includes:

* Ball-by-ball match data
* Toss results
* Match winners
* Batting statistics
* Bowling statistics
* Innings information
* Over-by-over scoring details

The analysis uses historical IPL match data across multiple seasons to identify long-term trends and performance patterns.

# 📊 Key Insights

## ✅ Toss Impact

Winning the toss had surprisingly little impact on match outcomes, with toss winners winning only around **50%** of matches.

## ✅ Chasing Advantage

Teams batting second won approximately **54%** of matches, highlighting a noticeable chasing advantage in IPL games.

## ✅ Toss Decision Strategy

Teams choosing to field first after winning the toss performed significantly better than teams choosing to bat first.

## ✅ Match Phase Analysis

Middle overs showed the largest scoring difference between winning and losing teams, indicating that this phase plays a crucial role in deciding match outcomes.

## ✅ Match Competitiveness

Nearly **one-third** of IPL matches were closely contested, emphasizing the unpredictable and competitive nature of T20 cricket.
